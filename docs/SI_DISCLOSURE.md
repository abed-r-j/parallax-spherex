# Use of SI in ParallaX

> It was drafted by the SI assistant itself. Only you know who proposed what; correct any
> sentence below that says more, or less, than what happened.

NASA Space Apps 2026 uses the name "Super Intelligence (SI)" for what is usually called
artificial intelligence, and requires teams to say where and how such tools were used. This
page is that statement for ParallaX, by team ZENITH LABS.

## Short version

The team chose the challenge, the goal and the direction: a comparison of SPHEREx dates that
accounts for the changing wavelength. The specific method (a per-pixel chromatic template
checked against two baselines) was worked out with the SI assistant (Claude, by Anthropic),
which also surveyed existing tools, wrote the code and drafted the documents under the team's
direction. The team reviewed the work, ran it and is responsible for it. All results are
computed by the project's own code from real SPHEREx data. No SI-generated images, video,
voices or faces are used.

## Which tool

One tool: Claude, a large language model by Anthropic, used as a research, coding and writing
assistant in the team's development environment. No image generator, voice generator, video
generator or other generative model was used. ParallaX itself contains no machine-learning
model and no language model: every step of the pipeline and the web app is ordinary,
deterministic numerical code that can be read and re-run.

## What the team did

* Chose the challenge, the goal and the direction: compare SPHEREx dates in a way that
  accounts for the wavelength changing at every visit.
* Directed the work step by step, decided what to keep and what to drop, and decided to
  publish the unfavourable findings (see `RESULTS.md`, section 2.2).
* Ran the pipeline, the tests and the app on the team's own computer, and reviewed the code,
  the numbers and the documents.
* Is responsible for everything that is submitted.

## What the SI assistant did, under that direction

| Part | Role of the assistant |
|---|---|
| Method | worked out, with the team, the specific method: a per-pixel chromatic template, checked against a naive pair and a wavelength-gated pair on the same real frames |
| Research notes | surveyed existing tools; gathered and checked the challenge text, the rules, the archive interfaces and the literature; each claim was marked verified or unverified |
| Python pipeline (`pipeline/src/parallax`, `pipeline/scripts`, `pipeline/tests`) | wrote the code and the tests; ran them and reported what failed |
| Web app (`web/src`, `web/scripts`) | wrote the code and the tests; took and inspected screenshots of the real build |
| Documents (this folder, `README.md`, the report, the paper, the slides, the scripts, the submission texts) | drafted the text from the measured results; the team reviewed it |
| Figures | none are generated by an SI model. Every figure is a plot made by the project's code (matplotlib) from real SPHEREx data, or a screenshot of the running app. The plotting code was written by the assistant |

## How it is marked

* Every source file written with the assistant carries the line "SI disclosure: written with
  the help of an SI coding assistant (Claude), checked by the team." in its header.
* The app's About page has a "Use of SI" section.
* The README, the project report and the submission form state it.
* There is no SI-generated image, video or audio in the project, so there is nothing to
  watermark. If that ever changes, the item will carry a visible "SI-generated" mark.

## What SI was not used for

* Not for producing any result. Every number in `RESULTS.md` is the output of
  `pipeline/scripts/run_ledger.py` and `run_validation.py` on real SPHEREx Level-2 images.
  Nothing is simulated in the judged path except the artificial test sources that the
  injection-recovery test adds to real frames, and those are labelled as such.
* Not for making images of the sky, of the spacecraft, of people, or of any logo or mission
  identifier.
* Not inside the tool: ParallaX makes no SI or machine-learning inference at run time.

## Attribution of outputs

The detections, classifications and measurements shown by ParallaX are outputs of the
ParallaX code. They are not NASA products and must not be attributed to NASA. NASA is not
responsible for their accuracy. ParallaX is not affiliated with or endorsed by NASA.
